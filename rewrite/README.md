# Новый бэкенд MelodyTrack

Изолированная основа бэкенда новой версии. Требования и архитектура находятся в [спецификации](../specification/README.md).

Solution: [MelodyTrack.Rewrite.slnx](MelodyTrack.Rewrite.slnx). Используется .NET SDK 10.0.402 с переходом на последующие исправления этой feature band, целевая платформа — `net10.0`.

| Проект | Язык | Назначение |
| --- | --- | --- |
| `src/MelodyTrack.Rewrite.Domain` | F# | Предметные модели и правила |
| `src/MelodyTrack.Rewrite.Application` | F# | Прикладные операции и порты |
| `src/MelodyTrack.Rewrite.Persistence` | F# | Работа с БД и реализация портов |
| `src/MelodyTrack.Rewrite.Api` | C# | Web API и host |
| `src/MelodyTrack.Rewrite.Init` | F# | Миграции и инициализация БД |

В `tests/MelodyTrack.Rewrite.Init.Tests` находится F#-проект xUnit v3 с Microsoft.Testing.Platform v2. Модульные тесты проверяют генерацию миграций, интеграционные используют Testcontainers.PostgreSql: один контейнер и отдельная база на сценарий. Нужен Docker. Также собирается и исполняется тестовый реестр SQL/F#, включая F#-обработчик с внешней зависимостью. Настройки исходной solution не меняются.

Ссылки проектов соответствуют согласованному каркасу: `Application → Domain`, `Persistence → Application/Domain`, `Api → Application/Persistence`, `Init → Persistence`.

Проекты и сборки имеют префикс `MelodyTrack.Rewrite`, поэтому не совпадают со сборками исходной версии, включая `MelodyTrack.Init`. В корневую `MelodyTrack.slnx` они не включены. Собственные `Directory.Build.props`, `Directory.Packages.props` и `global.json` отделяют настройки новой версии от старой; корневой `.gitignore` применяется и к этому каталогу.

`Api` запускает пустой host без маршрутов на `http://localhost:5280`; старая версия сохраняет порт 5000. `Init` использует сгенерированный при сборке общий реестр SQL/F# без рефлексии и поиска файлов при запуске. Он блокирует параллельный Init, проверяет историю и применяет ожидающие шаги, фиксируя каждый шаг и запись истории одной транзакцией. Обработчик получает подключение, транзакцию, отмену и логгер. Коды завершения: 0 — успех, 1 — ошибка, 130 — отмена. Предметная схема, авторизация, Quartz, SqlHydra и frontend ещё не реализованы. Подробности — [README миграций](src/MelodyTrack.Rewrite.Init/Migrations/README.md).

Версии зависимостей управляются локальным CPM. Persistence использует Npgsql, Init — Microsoft.Extensions.Hosting; проекты F# явно ссылаются на FSharp.Core. Остальные зависимости добавляются по мере реализации.

## Базовые настройки

- `.editorconfig`: независимые правила новой версии — UTF-8, LF, четыре пробела для C#/F#, два для JSON/XML и файлов проектов.
- `.gitattributes`: нормализация текстовых файлов и LF для исходников и конфигурации.
- `.gitignore`: локальные `.env` и файлы настроек; общие исключения сборки и IDE наследуются из корня репозитория.
- Источники NuGet наследуются из корневого `nuget.config`; версии новой версии управляются своим `Directory.Packages.props`.
- API и Init имеют собственные `appsettings.json`, `appsettings.Development.json` и профили запуска Development. Библиотеки получают настройки от запускающего приложения.

В обоих приложениях предусмотрен ключ `ConnectionStrings:Database` с пустым значением. Реальную строку подключения нужно передавать через переменную окружения `ConnectionStrings__Database`; секреты в отслеживаемые файлы не добавляются. `.env` и `appsettings.Local.json` автоматически не загружаются — исключение из Git само по себе не подключает конфигурационный провайдер.

API использует стандартный `WebApplication.CreateBuilder`, Init — Generic Host. Init читает appsettings из каталога приложения, куда JSON-файлы копируются при сборке и публикации; переменные окружения и аргументы командной строки могут переопределять значения. Профиль Init устанавливает `DOTNET_ENVIRONMENT=Development`. При ошибке подключения выводится тип ошибки без её сообщения и подробностей, которые могут содержать параметры подключения. Ошибка применения миграции дополнительно указывает имя файла и SQLSTATE для ошибок PostgreSQL; исходное исключение сохраняется для отладчика, но не передаётся логгеру.

Проверки: копирование конфигурации и SQL ранее подтверждено публикацией. После перехода на генерацию прошёл 31 тест: 17 модульных и 14 интеграционных на PostgreSQL через Testcontainers. Генерация, компиляция и выполнение смешанного реестра SQL/F# проверены тестовым проектом; данные работающей версии не используются. По D-391 ассистент работает небольшими порциями с ручным ревью пользователем.
