# Текущая задача

## Цель и статус

Мобильное меню, сворачивание десктопной панели, иконографика каталога, сохранение таблицы при обновлении, поиск по части ФИО и очистка завершённых аудитов реализованы в ветке `design/melodytrack-v2`. По запросу пользователя выполнены полные backend, frontend и browser scopes; обнаруженные ошибки исправлены, итоговые прогоны успешны. Изменения оформлены отдельными коммитами интерфейса, поиска и очистки документации по поручению пользователя. Push не выполнялся.

## Согласованный результат

- Горизонтальные мобильные вкладки заменены выдвижным Ant Design Drawer с вертикальной прокруткой разделов и кнопкой Tabler в хедере. Переход по разделу закрывает меню.
- Мобильная версия перенесена в footer самого меню; постоянный footer под содержимым удалён. Открытие истории версий закрывает меню.
- Десктопная панель сворачивается до 76px: навигация по иконкам, активный раздел и доступные имена сохранены. Подсказки навигации, кнопки сворачивания и версии используют стандартный `title` только при свёрнутой панели; в развёрнутом и мобильном меню подсказок нет. Кнопка сворачивания находится слева в хедере основного содержимого, справа от логотипа боковой панели; на телефоне скрыта. Версия представлена иконкой истории с номером в подсказке; доступ к истории учитывает прежние права. Состояние панели хранится в React до перезагрузки. Мобильное меню остаётся с подписями независимо от состояния панели.
- «Помощь» и «Обновить» в каталоге представлены иконками Tabler с доступными именами и подсказками. Архивный статус в таблице и карточке получил иконку.
- Сортировка DataView и раскрытие меню профиля используют Tabler вместо текстовых стрелок.
- При изменении фильтров, сортировки и страницы каталог сохраняет показанные данные до нового ответа. Индикатор обновления не сдвигает таблицу; пагинация описывает показанные строки. При утрате доступа данные очищаются. Подпись «Разделы» над десктопной навигацией удалена.
- По подтверждению пользователя поиск расширен буквальным вхождением части нормализованного ФИО; допуск трёх опечаток полного ФИО сохранён. SQL, учебная модель, инструкция и регрессионные сценарии согласованы. Миграция и реальные данные не менялись.
- По уточнению пользователя данные о записях не подключаются: обе даты имеют отключённые кнопки сортировки с пояснением. Серверные запросы и контракты не менялись.
- Удалены завершённые `frontend-ui-library-audit.md`, `test-quality-audit.md`, `test-audit-backend.md`, `test-audit-session.md`, `test-audit-ui.md`. Ссылки заменены существующим процессом проверок; актуальные предметные и инфраструктурные аудиты сохранены. История удалённых отчётов остаётся в Git.
- Актуализированы `web/README.md`, `docs/client-directory.md` и индекс ограничений.
