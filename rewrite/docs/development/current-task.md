# Текущая задача

## Цель и статус

Ветка `design/melodytrack-v2`. Пачка реализована и проверена: аккордеоны и отдельные тренировки, удаление обучения входу и поиск с опечатками во фрагменте ФИО. По запросу пользователя изменения разделены на коммиты: `e127bcb` — поиск, `0cdf0f1` — обучение; очистка таймеров тестов и этот снимок сохраняются отдельным коммитом проверок. Push не поручен.

## Согласованный результат

- Обучение: основной элемент — аккордеон темы с описанием и вложенными аккордеонами подтем. Кнопка запуска тренировки находится внутри своей темы; префикс «Инструкция» удаляется. Обучение и тренировка входа исключены, поскольку сотрудник уже авторизован.
- Тренировки разделены на поиск/фильтры, сортировку и карточку. У каждой своя кнопка внутри соответствующей подтемы; карточка больше не прикреплена к таблице. Поиск использует заданный порядок, сортировка — заданные фильтры. Общее прохождение списка сохраняется после обеих проверок в одном сеансе provider; существующее сохранённое прохождение и формат остаются прежними. Карточка сохраняет отдельный локальный результат, как и раньше. Детали — README feature.
- В окне тренировки только выбранное упражнение, без вкладок и текстовой статьи. Материалы остаются в аккордеонах страницы обучения. Яркие информационные плашки заменены короткой приглушённой подписью; настоящие данные не меняются.
- Источник требований обучения обновлён: `../specification/employee-training.md`. Права, демонстрационные данные, персональный прогресс и его отделение от чтения статьи сохраняются.
- Поиск: пример «багд» должен находить «Богданова Полина». Пользователь выбрал до трёх вставок, удалений или замен для любого фрагмента без уменьшения допуска на коротких запросах. Поэтому запросы до трёх символов совпадают с любым непустым ФИО. `%` и `_` остаются обычными символами, участвующими в том же сравнении.
- SQL-функция добавляется отдельным шагом `0017_AddClientNameFragmentSearch.sql`; прежние шаги неизменны, карточки и история не преобразуются. До обновлённого API требуется обычный Init; на реальных данных он не запускался. Контракт поиска и технические ограничения — `docs/client-directory.md`, README миграций.
- Backend и учебная модель используют поиск фрагмента динамическим программированием; нормализация регистра и пробелов сохраняется. Добавляются регрессионные сценарии трёх/четырёх изменений, середины ФИО, Unicode и длинных строк.
