# Текущая задача

## Цель и статус

Ветка `design/melodytrack-v2`. По поручению пользователя в неё объединена локальная `feature/offline-v2` с первой порцией офлайна (`fa36c07`). Конфликты реестра решений и этого снимка разрешены с сохранением требований обеих веток. Push не поручен.

Текущая порция согласования аналитики завершена и сохранена коммитом `fa9704f`; основной источник — [спецификация аналитики](../../../specification/analytics-and-dashboards.md), оставшиеся вопросы — её раздел «Открытые решения». Реализация аналитики не начата. D-546 сохраняется: статистика требует интернета, включая чтение виджетов и редактирование запросов.

Активное направление — офлайн. Слияние возвращает ранее законченную первую порцию; следующая реализация пока не начата.

## Согласованный результат

- [Проект офлайн-синхронизации](../offline-sync.md) отделяет действующие требования от предложений общего протокола. D-543–D-545 сохранены в [аутентификации](../../../specification/authentication.md) и реестре решений без перенумерации.
- Первая порция: зашифрованное хранилище аккаунта, открытие при парольном входе и отдельная ручная разблокировка, закрытие при выходе во всех вкладках, черновик нового клиента и ручной повтор устойчивой команды создания с неизменными `commandId`/`clientId`/данными.
- Native IndexedDB/Web Crypto: AES-GCM-256, PBKDF2-SHA256 600 000, случайные salt/IV, AAD и строгие версии; ключ только в памяти. Обнаруженный отзыв клиентских прав удаляет данные первой базы по D-528.
- Неотправленные изменения и конфликты автоматически не удаляются. Кэш хранится 30 дней без использования, подтверждённые команды — 30 дней; необходимые ожидающим командам исходные данные сохраняются вместе с ними.
- Подтверждённый экстренный сброс пароля допускает удаление всей локальной работы; обычная смена пароля и ошибка расшифровки такого основания не дают. Серверный признак сброса и переобёртка ключа при обычной смене ещё не реализованы. Действие «Забыть» остаётся открытым D-282.
- Разделение кода Vite через Rolldown и динамические импорты каталога клиентов/рабочей страницы сохранено; порог предупреждения о большом чанке не повышен.
- Service worker, запуск без сети, локальный каталог/карточки/справочники, автоматическая очередь доставки, редактирование существующих карточек/заметок и редактор конфликтов отсутствуют. Общий receipt/outbox/pull-протокол остаётся предложением; текущий create-replay возвращает актуальную карточку, а не неизменный receipt.

## Следующее действие

Ближайшая порция офлайна — кэш ранее полученных серверных данных по [проекту](../offline-sync.md): каталог клиентов с параметрами страницы, открытые карточки и справочники, изоляция аккаунтов, явная неполнота локального поиска и сохранность ожидающих команд. Запуск без сети и достоверный серверный признак сброса пароля требуют отдельных интеграций. Не расширять эту порцию на статистику по D-546.

Вопрос о широте поиска ФИО остаётся в [активном реестре](../open-questions.md#допустимая-широта-поиска-по-фио-с-опечатками--п1).
