# Текущая задача

## Цель и статус

Исправления [аудита frontend](../frontend-ui-library-audit.md), разбор успешных ответов API и перенос runtime/API ошибок в Sonner завершены. Ветка `design/melodytrack-v2`, исходный commit `0ea6e06`. Пользователь подтвердил визуальную работу интерфейса и поручил коммит изменений. Итоговый frontend pipeline успешен; Chromium успешен, WebKit заблокирован системными зависимостями. Push не запрошен.

## Согласованный результат

- Невалидный ручной ввод даты устанавливает custom validity общего `DateInput`. Редактор клиента блокирует сохранение, показывает ошибку и фокусирует дату; исправление или очистка снимает блокировку. Сохранение прежнего значения при ошибочном видимом вводе исключено.
- Необъявленный CSS-токен `--color-border` в каталоге клиентов и обучении заменён существующим `--color-line`.
- Редактор клиента использует семантическую форму с submit-кнопкой, поддерживает отправку по Enter, связывает ошибки обязательных полей с сообщением через ARIA и фокусирует первое ошибочное поле. Прежние правила валидации контактов сохранены.
- Тема устанавливается синхронным скриптом в `web/index.html` до запуска React. Сохранённый выбор имеет приоритет, недоступное хранилище допускает системную тему. Переключение синхронизирует атрибут, фон, color-scheme и theme-color через layout effect; next-themes не добавлен.
- Установлен Sonner 2.0.8; общий Toaster использует бумажные токены обеих тем. Runtime/API ошибки не занимают место в потоке, повторяемые чтения имеют retry. Таблица сохраняет строки при фоновом отказе; ошибки полей, конфликты черновиков и постоянные инструкции остаются inline. Ant Design/Tabler сохранены; полная миграция foundation не включена.
- Валидаторы каталога и карточки допускают пустые необязательные строки по HTTP-контракту. В development ошибка разбора каталога называет статический путь поля без значений ответа. Точная причина исходного отказа чтения не доказана: текущие backend DTO/OpenAPI/Kiota согласованы, исходного ответа нет. Отдельное промежуточное падение `failed is not defined` в DataView устранено удалением оставшегося условия пагинации.
- Обновлены `web/README.md`, README общего ввода даты и статус отчёта аудита. C#, серверный HTTP-контракт, бизнес-правила и данные не менялись.

Добавлены регрессионные unit-сценарии даты/формы, разбора ответа через настоящий Kiota и жизненного цикла уведомлений; браузерные сценарии ранней темы до React и недоступного storage.
