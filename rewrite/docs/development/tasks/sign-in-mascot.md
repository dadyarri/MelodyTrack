# Маскот-гитара на странице входа

## Цель и статус

По прямому поручению пользователя добавлен SVG-маскот-гитара с реакциями
на ввод логина и пароля и вход с ключом. Маскот выглядывает из-за правого края
карточки с наклоном вверх, на экранах уже 1024px скрыт.
Реализация завершена; итоговые frontend- и браузерные проверки прошли.
Изменения сохранены отдельным коммитом. Push не поручен.

## Результат

- `GuitarMascot.tsx` и CSS Module находятся рядом с `StaffSignInForm`.
  Гитара нарисована с нуля в SVG: деревянный корпус, гриф, струны,
  резонатор-рот, глаза, ручки и ножки. Новых зависимостей нет.
- Иллюстрация шириной 340px размещена абсолютно справа относительно
  карточки с поворотом 28°. Подложка карточки перекрывает часть корпуса;
  лицо и правая ручка выступают за правый край. Отступ страницы резервирует
  место для иллюстрации. На экранах уже 1024px маскот скрыт без пустого места.
- При фокусе в логине глаза и небольшой наклон корпуса следуют позиции
  курсора, включая перемещение по уже введённому тексту.
- При фокусе внутри группы пароля ручки закрывают глаза. Кнопка показа
  вызывает подглядывание; скрытие пароля возвращает закрытую позу.
  При выходе из поля персонаж возвращается в покой.
- При фокусе и нажатии входа с ключом (включая второй фактор) гитара
  поднимает ключ в правой руке. Поза сохраняется на время passkey-запроса;
  подготовка challenge в фоне её не включает. Вызов WebAuthn остаётся
  непосредственно в обработчике пользовательского события.
- Ключ увеличен до кольца диаметром 30 SVG-единиц и длинного стержня
  с зубцами; золотистая заливка отделена толстым тёмным контуром.
- После успешного интерактивного входа маскот выполняет кивок 600 мс.
  `app/useSignInCompletion` удерживает представление страницы входа 650 мс,
  не задерживая аутентификацию или изменения сессии. Форма сообщает
  «Вход выполнен» и блокирует повторную попытку. При восстановлении сессии,
  скрытом маскоте или reduced motion переход выполняется сразу.
- Маскот не получает значения логина и пароля, не меняет отправку формы,
  не перехватывает указатель и исключён из accessibility tree.
  CSS-переходы включены только при `prefers-reduced-motion: no-preference`.
- `PaperPasswordInput` сообщает о переключении видимости через необязательный
  callback; остальные потребители сохраняют прежнее поведение.
- Добавлены тесты движения взгляда/blur, закрывания/подглядывания
  с переходом фокуса на кнопку, повторного входа после второго фактора
  и сохранения позы с ключом при ожидании аутентификации.
- Добавлены тесты завершающей позы и маршрутизации: 650 мс после обычного
  и мгновенного ответа, отсутствие паузы при restore/отключённой анимации,
  отмена паузы при очистке сессии.
