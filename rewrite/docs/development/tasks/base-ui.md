# D-565: полная миграция Base UI

## Цель и статус

Миграция по утверждённому
[плану D-565](../../../../specification/architecture.md#миграция-rewriteweb-с-ant-design-на-base-ui--d-565)
завершена: интерфейсы переведены на Base UI и CSS Modules, Ant Design удалён,
пункт «Локальные данные» получил иконку базы данных. Миграция и плавные
переходы сохранены отдельными коммитами. Push не поручен.

## Результат

- Перенесены оболочка, меню, панели клиентов и редактор, вход и приглашения,
  обучение, локальное хранилище, история выпусков, таблицы и пагинация.
- Общие примитивы находятся в `web/src/shared/ui/paper/`: кнопки, поля,
  переключение видимости пароля, Select, Tooltip, Drawer, Dialog, Accordion
  и пагинация. Формы используют React Hook Form, QR — qrcode.react,
  пагинация — react-paginate; версии зафиксированы в package/lockfile.
- Удалены зависимости Ant Design, ConfigProvider, reset, специальные
  CSS-селекторы и настройки сборки. Все кастомные компоненты используют
  CSS Modules; глобальный `app/styles.css` содержит токены и стили документа.
- Сохранены мобильный ввод, светлая/тёмная темы порталов, вложенные попапы,
  возврат фокуса и общая граница прокрутки `data-popup-scroll-boundary`.
  Панель просмотра приостанавливается на время редактирования; закрытие
  редактора возвращает выбранную карточку. Ширина редактора — 560px.
- Заметки пересчитывают высоту при вводе и изменении ширины через
  ResizeObserver; после десяти строк используется внутренняя прокрутка.
- Независимое ревью выявило и помогло исправить активный пункт навигации,
  объяснение недоступного добавления клиента, имя выбора размера страницы
  и утраченные при замене Input.Password кнопки показа пароля.
- API, права и шифрованное хранение не менялись. Документация frontend
  и календарных компонентов актуализирована.
- Исправлен runtime-импорт `react-paginate`: UMD entry в Vite 8 возвращает
  объект с `default`, поэтому `PaperPagination` явно получает компонент.
  Регрессионный браузерный сценарий воспроизводил `Element type is invalid`
  во всех трёх браузерах до исправления и проверяет страницы/размер выдачи
  после него. Прежние browser fixtures содержали только одну страницу данных.
- Для показа/скрытия пароля (включая локальное хранилище), стрелок пагинации,
  закрытия окна и индикаторов Select/Accordion используются Tabler Icons.
  Доступные имена действий сохранены; у переключателей пароля есть подсказки
  и зона нажатия 44px. Основные действия форм сохраняют текстовые подписи.
- Добавлены короткие переходы 120–200 мс: появление попапов, сдвиг Drawer,
  раскрытие Accordion, состояния кнопок, полей и навигации. Стили находятся
  в CSS Modules и используют состояния Base UI без JS-таймеров.
  При `prefers-reduced-motion: reduce` переходы отключены, индикаторы
  загрузки статичны. Браузерные сценарии проверяют обе настройки и фокус.

## Итоговые проверки

- Frontend: `.artifacts/agent-checks/20261118T173916-7ed11c46/report.json`,
  success/exit 0: Biome, TypeScript, **225/225 тестов**, production build.
  Мутации форматтера просмотрены.
- Browser: `.artifacts/agent-checks/20261118T173922-47f09679/report.json`,
  success/exit 0: полный scope, **54 сценария: 51 passed, 3 skipped**.
  Chromium, desktop WebKit и mobile WebKit проверяют календарь, вложенные
  попапы, возврат фокуса, карточку/редактор, видимость пароля, иконку и диалог
  локальных данных, темы, прокрутку и многостраничную пагинацию через Vite,
  диалог и Accordion с обычной и уменьшенной анимацией.
  Пропуски: виртуальный WebAuthn в двух
  WebKit и mouse wheel в mobile WebKit.
- Browser suite запускался в установленном Playwright 1.65.1-контейнере
  с Node 26. Обычная Docker-сеть нужна для онлайн-сценариев:
  `--network none` устанавливает `navigator.onLine=false` и блокирует SSE.
- HTTP business outcomes в browser suite синтетические; это не приёмка
  с реальным backend или аппаратным WebAuthn. ResizeObserver заметок
  проверен по коду, отдельный браузерный сценарий изменения ширины не добавлен.
