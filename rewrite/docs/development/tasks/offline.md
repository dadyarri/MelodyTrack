# Офлайн: состояние первой порции

## Цель и статус

Ветка `design/melodytrack-v2`. По поручению пользователя в неё объединены локальная `feature/offline-v2` с первой порцией офлайна (`fa36c07`) и PR #15/#16. PR #15 добавляет план перехода на Base UI: с разрешения пользователя его решение перенумеровано с занятого D-543 на D-565, существующие ID сохранены. PR #16 переключает GitHub Actions на rewrite. Push не поручен.

Текущая порция согласования аналитики завершена и сохранена коммитом `fa9704f`; основной источник — [спецификация аналитики](../../../../specification/analytics-and-dashboards.md), оставшиеся вопросы — её раздел «Открытые решения». Реализация аналитики не начата. D-546 сохраняется: статистика требует интернета, включая чтение виджетов и редактирование запросов.

Порция отказа от шифрования по обновлённому D-545 завершена и проверена. Пользователь подтвердил удаление прежних зашифрованных локальных данных при переходе: ценных черновиков нет. Изоляция аккаунтов, блокировка выхода D-543 и сроки D-544 сохраняются. Кэш серверных данных пока не реализуется.

## Согласованный результат

- [Проект офлайн-синхронизации](../../offline-sync.md) отделяет действующие требования от предложений общего протокола. D-543–D-545 сохранены в [аутентификации](../../../../specification/authentication.md) и реестре решений без перенумерации.
- Первая порция: хранилище аккаунта в IndexedDB, закрытие при выходе во всех вкладках, черновик нового клиента и ручной повтор устойчивой команды создания с неизменными `commandId`/`clientId`/данными.
- D-545: данные без шифрования, автоматический доступ для текущего сотрудника после входа/восстановления действующей сессии без дополнительных ключей. Cookie-восстановление не снимает отметку явного выхода. Обнаруженный отзыв клиентских прав удаляет данные первой базы по D-528.
- Неотправленные изменения и конфликты автоматически не удаляются. Кэш хранится 30 дней без использования, подтверждённые команды — 30 дней; необходимые ожидающим командам исходные данные сохраняются вместе с ними.
- Смена и сброс пароля не управляют локальными данными. При обновлении базы с версии 1 на 2 прежние зашифрованные записи удаляются по явному разрешению; отметки выхода и обязательной очистки сохраняются. Действие «Забыть» остаётся открытым D-282.
- Разделение кода Vite через Rolldown и динамические импорты каталога клиентов/рабочей страницы сохранено; порог предупреждения о большом чанке не повышен.
- Service worker, запуск без сети, локальный каталог/карточки/справочники, автоматическая очередь доставки, редактирование существующих карточек/заметок и редактор конфликтов отсутствуют. Общий receipt/outbox/pull-протокол остаётся предложением; текущий create-replay возвращает актуальную карточку, а не неизменный receipt.

- Frontend: `.artifacts/agent-checks/20261118T190257-0c461859/report.json`, success/exit 0. `npm run verify:fix` через Node 26: Biome, TypeScript, 236/236 тестов, production build. Ошибки типов в новых тестах исправлены до полного повторного запуска; мутации форматтера просмотрены.
- Browser: `.artifacts/agent-checks/20261118T190433-8eee0e33/report.json`, success/exit 0; 57 сценариев, 54 прошли, 3 предусмотренных пропуска (виртуальный WebAuthn в двух WebKit и native wheel на мобильном). Переход базы, открытые записи, изоляция аккаунтов, блокировка и сроки проверены в Chromium, WebKit и мобильном WebKit.

Пути `/workspace` в контейнерном отчёте соответствуют корню rewrite. Артефакты локальные, их наличие в другом checkout не гарантировано. C#/MSBuild эта порция не меняет и не проверяет.

## Следующее действие

Следующая независимая порция — кэш ранее полученных серверных данных по [проекту](../../offline-sync.md): каталог клиентов с параметрами страницы, открытые карточки и справочники, изоляция аккаунтов, явная неполнота локального поиска и сохранность ожидающих команд. Запуск без сети требует отдельной интеграции. Не расширять эту порцию на статистику по D-546. Push не поручен.
