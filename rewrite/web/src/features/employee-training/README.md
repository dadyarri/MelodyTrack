# Обучение сотрудников

Основание: D-511–D-517, D-538 и `specification/employee-training.md`.

`EmployeeTrainingProvider` монтируется только после получения серверной личности сотрудника. `staffId` — обязательная граница персонального прогресса. При смене личности внутренний provider перемонтируется, незавершённые чтения и транзакции IndexedDB отменяются. Токены, пароли и настоящие клиентские данные в хранилище обучения не попадают.

Экспортируются `TrainingWorkspace` и `useEmployeeTraining()`. Hook предоставляет `progress`, `ready`, `active`, `storageAvailable`, `openClientTraining()`; интерфейс приложения может открывать тренировку из темы и контекстной помощи. Чтение статьи не завершает упражнение. Отсрочка сохраняется отдельно и запрещает следующий автоматический запуск этого модуля.

Основной элемент страницы — аккордеон «Список клиентов» с описанием и вложенными темами поиска, сортировки, карточки и состояния работы. Поиск и фильтры, сортировка и карточка имеют отдельные кнопки запуска внутри своих тем. Каждая открывает только соответствующее упражнение: форма карточки не добавляется под таблицу. В упражнении поиска порядок строк уже задан; в упражнении сортировки заранее настроены поиск и фильтры. После успешной проверки доступны переходы между этими двумя упражнениями. Состояние работы и заметки пока представлены только текстом. Названия не содержат префикса «Инструкция». Окно тренировки содержит только упражнение без вкладок; текстовые материалы доступны в аккордеонах раздела «Обучение». Обучение и демонстрация входа удалены: сотрудник уже авторизован. Эти действия не обращаются к backend и не меняют настоящую сессию. Результат не выдаёт прав.

`openClientTraining()` открывает поиск и фильтры; `openClientTrainingTopic(topic)` открывает выбранную тему. Общее прохождение списка сохраняется после успешных проверок поиска/фильтров и сортировки в текущем сеансе provider, в любом порядке. Частичные результаты этих двух блоков живут в памяти до смены аккаунта или перезагрузки; формат сохранённого общего результата не меняется. Ранее пройденный список не становится незавершённым. Карточка остаётся отдельной практикой с локальным результатом сохранения и не меняет общий признак прохождения списка.

Пройденную тренировку можно повторить: повторная демонстрация живёт только в памяти provider и не меняет сохранённое прохождение, прочтение статьи или отсрочку. Она не делает модуль снова обязательным. Закрытие повторной демонстрации убирает только её временное состояние.

Прогресс версии 1 хранится локально в IndexedDB по `staffId`. Старые поля обучения входу сохраняются для чтения существующих записей, но не запускают модалки, напоминания или блокировку работы. Существующее прохождение и отсрочка тренировки клиентов сохраняются. Запись будущего или некорректного формата не перезаписывается. При отказе хранилища сохраняется работа в памяти текущей вкладки с понятным предупреждением.

Раздел «Список клиентов» содержит текст и тренировку поиска, сочетания фильтров и сортировки. Демонстрационный DataView работает только с локальным набором вымышленных клиентов, без HTTP-запросов. Локальная учебная эмуляция сравнивает запрос с любым фрагментом ФИО с расстоянием Левенштейна до трёх изменений, нормализуя регистр и пробелы без подмены `ё` на `е`. Допуск одинаков для всех длин: запросы до трёх символов совпадают с любым непустым ФИО. Рабочий поиск выполняется PostgreSQL, учебный алгоритм в нём не используется. Упражнение засчитывается после проверки выбранных условий и полученного состава/порядка строк; чтение статьи и нажатие проверки с неверным результатом не завершают его. Повтор доступен без сброса сохранённого прохождения.

Доступ к модулю передаётся в provider через `canUseClientDirectory` из актуального разрешения чтения клиентов; по умолчанию модуль закрыт. Область «свои» не препятствует синтетической тренировке. Отзыв разрешения закрывает открытую тренировку и убирает её запуск/напоминание, но не удаляет историю прохождения.

Поле `clientDirectory` имеет собственную версию 1 и отдельные завершение/отсрочку. Старые записи без него читаются с незавершённым новым упражнением; прохождение входа, прочтение и отсрочка сохраняются. Сохранение из старой вкладки не стирает уже записанное прохождение другой вкладки. Неизвестная версия нового поля, как и всего прогресса, не перезаписывается.

При загрузке прогресса доступная незавершённая тренировка клиентов открывается автоматически, если её не откладывали. Отложенную или пройденную тренировку сотрудник открывает вручную из темы; отзыв доступа закрывает её. Старый модуль входа не запускается независимо от его прогресса. Серверного HTTP-контракта обучения пока нет. Эта порция не заявляет синхронизацию между устройствами, обработку серверных конфликтов или доставку будущих версий. Правила автозапуска обновлённых частей в начале рабочего дня D-515/D-524 потребуют отдельного серверного контракта графика и версий. Новые версии материалов не подменяются молчаливым сбросом прогресса.
