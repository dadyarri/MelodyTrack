# Обучение сотрудников

Основание: D-511–D-517, D-538 и `specification/employee-training.md`.

`EmployeeTrainingProvider` монтируется только после получения серверной личности сотрудника. `staffId` — обязательная граница персонального прогресса. При смене личности внутренний provider перемонтируется, незавершённые чтения и транзакции IndexedDB отменяются. Токены, пароли и настоящие клиентские данные в хранилище обучения не попадают.

Экспортируются `TrainingWorkspace` и `useEmployeeTraining()`. Hook предоставляет `progress`, `ready`, `storageAvailable`, `openTraining()` и `openArticle()`; интерфейс приложения может открывать обучение и контекстную помощь. Чтение статьи не завершает упражнение. Отсрочка сохраняется отдельно и запрещает следующий автоматический запуск этого модуля.

Учебная сессия открывается по кнопке запуска обучения, без логина, пароля и сетевого запроса. При первом автоматическом показе модуля используется кнопка «Начать обучение»; ручное открытие/продолжение тренировки сразу открывает учебный аккаунт. Выход из демонстрации завершает упражнение. Эти действия не обращаются к backend и не меняют настоящую сессию. Результат не выдаёт прав.

Пройденную тренировку можно повторить: повторная демонстрация живёт только в памяти provider и не меняет сохранённое прохождение, прочтение статьи или отсрочку. Она не делает модуль снова обязательным. Закрытие повторной демонстрации убирает только её временное состояние.

Прогресс версии 1 хранится локально в IndexedDB по `staffId`. Существующее прохождение и отсрочка сохраняются при изменении интерфейса запуска. Запись будущего или некорректного формата не перезаписывается. При отказе хранилища сохраняется работа в памяти текущей вкладки с понятным предупреждением.

Раздел «Список клиентов» содержит инструкцию и тренировку поиска, сочетания фильтров и сортировки. Демонстрационный DataView работает только с локальным набором вымышленных клиентов, без HTTP-запросов. Локальная учебная эмуляция сравнивает полное ФИО с расстоянием Левенштейна до трёх изменений, нормализуя регистр и пробелы без подмены `ё` на `е`; рабочий поиск выполняется PostgreSQL, учебный алгоритм в нём не используется. Упражнение засчитывается после проверки выбранных условий и полученного состава/порядка строк; чтение статьи и нажатие проверки с неверным результатом не завершают его. Повтор доступен без сброса сохранённого прохождения.

Доступ к модулю передаётся в provider через `canUseClientDirectory` из актуального разрешения чтения клиентов; по умолчанию модуль закрыт. Область «свои» не препятствует синтетической тренировке. Отзыв разрешения закрывает открытую тренировку и убирает её запуск/напоминание, но не удаляет историю прохождения.

Поле `clientDirectory` имеет собственную версию 1 и отдельные завершение/отсрочку. Старые записи без него читаются с незавершённым новым упражнением; прохождение входа, прочтение и отсрочка сохраняются. Сохранение из старой вкладки не стирает уже записанное прохождение другой вкладки. Неизвестная версия нового поля, как и всего прогресса, не перезаписывается.

Новый модуль открывается вручную из обучения; обновление интерфейса не вызывает его посреди работы и не перезапускает пройденный модуль входа. Серверного HTTP-контракта обучения пока нет. Эта порция не заявляет синхронизацию между устройствами, обработку серверных конфликтов или доставку будущих версий. Правила автозапуска обновлённых частей в начале рабочего дня D-515/D-524 потребуют отдельного серверного контракта графика и версий. Новые версии материалов не подменяются молчаливым сбросом прогресса.
