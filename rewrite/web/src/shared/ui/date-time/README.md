# Date and time inputs

`DateInput` принимает `YYYY-MM-DD | null`, `TimeInput` — `HH:mm | null`,
`DateTimeInput` — `YYYY-MM-DDTHH:mm | null`. Значения не содержат часовой пояс.
Владелец формы явно выбирает часовой пояс при преобразовании wall-clock времени в UTC.
Компоненты не преобразуют дату через локальный `Date` или `toISOString`.
Действие «Сегодня» и подсветка текущего дня используют Europe/Moscow.

Общие параметры: `value`, `onChange`, необязательные `id`, `aria-label`, `disabled`,
`min` и `max` в формате самого компонента. У DateInput/DateTimeInput есть `placeholder`.
Неполный ввод остаётся внутри компонента; невалидное значение не передаётся в onChange.
Ошибочный/неполный ручной ввод даты также устанавливает native custom validity
текстового поля. Форма должна учитывать его при отправке; при `noValidate`
владелец явно проверяет `validity.customError` и вызывает `reportValidity()`.
В составном поле onChange получает полное значение либо null при очистке.

Календарь имеет навигацию по месяцам и годам. В сетке доступны стрелки,
Home/End, PageUp/PageDown и Shift+PageUp/PageDown для года; Escape закрывает его.
Alt+ArrowDown из текстового поля открывает календарь. Ручной ввод даты принимает
ДД.ММ.ГГГГ и ISO, проверяется по Enter или при потере фокуса. Очистка явная.
Часы и минуты выбираются в отдельных элементах; системные date/time pickers не используются.

Поповер календаря использует Base UI. Он позиционируется относительно всего поля,
ограничивается viewport и наследует CSS-токены с `html` в портале.
Стили семейства изолированы в `ui/date-time.module.css`.
Нажатие на текстовое поле сохраняет фокус для ручного ввода; выбор даты возвращает
фокус в поле, Escape из календаря — на кнопку открытия. Escape во вложенном
календаре не должен закрывать содержащую его панель редактора.
