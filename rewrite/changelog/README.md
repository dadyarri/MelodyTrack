# Версия приложения и история изменений

`current.json` — единственный источник номера текущей версии приложения. API возвращает его в `/api/releases/current` и поле `currentVersion` истории `/api/releases`. Технический `AssemblyVersion` не используется как версия продукта; эта граница соответствует исходному приложению, где интерфейс также получал номер из changelog.

Файлы `releases/YYYY.MM.N.json` описывают регулярные версии, `YYYY.MM.N.P.json` — исправления. Формат и группировка `new`, `improved`, `fixed`, `security` перенесены из `MelodyTrack.Backend/Services/ReleaseChangelog.cs` текущей неразвёрнутой версии исходного приложения. Её старые записи не включаются в историю rewrite.

`date: null` — запись без объявленной даты публикации. Явно выбранная в `current.json` текущая версия включается в историю и показ изменений даже при такой дате; остальные неопубликованные записи не показываются. Это необходимая граница переноса: исходный loader показывал только датированные релизы, а для текущей версии rewrite пользователь определил номер и изменения без даты публикации. Дата не выдумывается. Опубликованная регулярная запись требует дату, кодовое имя с пояснением и хотя бы один пункт изменений. Исправление ссылается на опубликованную регулярную версию и наследует её имя.

Метаданные встроены в API как assembly resources: получение версии не зависит от рабочей директории, конфигурации БД или внешнего файла при publish. После изменения JSON нужна пересборка API. Build-time OpenAPI export использует те же ресурсы.

История показывает текущую версию первой, затем датированные релизы по дате и числовой версии; поддерживает `page` и `page_size` (по умолчанию 1 и 2; размер 1–50). API публичный, с rate limit, ETag и ответом 304 для неизменившихся данных. Номер текущей версии, запись изменений и техническая версия сборки не дублируются вручную в разных источниках.

Эта возможность переносит получение версии и просмотр истории. Создание release-веток, подготовка/публикация релиза и команды старого `ReleaseTool.cs` в данный контур не входят.
