# Стоимость, баланс и финансовые операции

Актуальные правила включают отдельный результат каждого участника, денежную оплату без новой сущности абонемента, финансовые права администратора и ответы D-448/D-450–D-454. История прежних абонементов описана отдельно в [историческом разделе](subscriptions.md); она не становится новым покрытием занятий.

## Оплата и цена участника — D-448/D-450

Клиент пополняет денежный баланс, за отдельные занятия списывается его стоимость. Каждый участник парной встречи платит обычную стоимость услуги, с применением своих согласованных скидок; цена не делится между двумя. Проведение/сгорание одного не создаёт списания у другого. Долг допустим и не блокирует запись D-061; 500 минус 1000 даёт -500.

Цена выбирается по времени окончания независимо от создания, материализации или поздней отметки. Новая цена действует с указанного момента включительно и не вводится задним числом D-192. Например, цена 1200 с 14:00 применяется к встрече 13:00–14:00, но не 13:00–13:45. Абсолютные моменты — UTC, отображение и календарные даты — Europe/Moscow.

Длительность созданной встречи/серии фиксирована по услуге и не меняется вместе с новой настройкой справочника. Цена для будущей встречи прежней серии берётся на её окончание. Пропорциональный пересчёт цены по длительности не выбран.

## Результаты и исправления

Проведение/сгорание отмечается вручную после окончания; до отметки списания по результату нет. Отмена участника без списания, для остальных встреча сохраняется. Задача о забытом результате D-429 не подтверждает проведение.

Результат понедельника, отмеченный в среду, уменьшает баланс в момент отметки, но относится к дате начала понедельничной встречи. Цена и применимость скидки — на её окончание. Участие клиента, дата встречи, время отметки и внесения платежа — разные факты.

Снятие результата исключает его финансовый эффект из вычисления баланса и возвращает использование скидки на N занятий D-451. Другие участники/встречи не получают перераспределения. Повторная отметка использует обычные правила времени и действующую активацию без новой активации кода. Нельзя задним числом менять цену или переписывать первичные платежи ради исправления результата.

Изменение общей даты проведённой встречи затрагивает результаты всех участников: сначала снимаются действующие результаты, затем меняется время, затем отмечаются результаты заново. Услуга и длительность остаются неизменными. Удаление ошибочной встречи не допускается с действующим списанием хотя бы одного участника; история сохраняется D-298.

## Маркетинговые кампании и промокоды

Супер создаёт кампанию с процентной либо фиксированной скидкой для новых или возвращающихся клиентов. После создания условия неизменны D-314. Можно остановить новые активации D-318 и удалить кампанию только без любых активаций D-320. Возобновление остановленной кампании не согласовано.

Администратор/супер активирует код клиенту один раз для одной выбранной услуги D-207/D-215. Клиент и преподаватель код не активируют. Сочетание скидок и выбор самой выгодной не нужны D-210. После активации скидка действует на N занятий либо индивидуальный срок; одноразовая активация не означает одно занятие.

Проведённый и сгоревший результаты расходуют по одному льготному использованию, отмена не расходует. Снятие результата возвращает использование в рамках той же активации D-451. Саму активацию нельзя отменить даже ошибочную до применения D-317; новый код для исправления результата не активируется.

Конец встречи должен быть строго раньше конечной границы индивидуального срока D-443; дата внесения результата не влияет. Общая дата конца кампании запрещает новые активации, но не обрывает уже предоставленный индивидуальный срок D-205.

Сумма после скидки ограничивается снизу нулём и округляется вниз до десятков рублей: 1872.5 → 1870. Превышающая цену фиксированная скидка даёт ноль без начисления разницы клиенту. Деньги в целом поддерживают копейки; это не округление всех платежей и расходов до десятков.

Новый клиент для кампании не имеет проведённых/сгоревших обычных занятий; консультации не учитываются D-211/D-212. Возвращающийся — после заданного в кампании перерыва от окончания последнего обычного проведённого/сгоревшего участия по любой услуге; будущие/отменённые и консультации не учитываются D-315. Консультация задаётся флагом услуги, не названием или нулевой ценой.

Код уникален среди всех сохранённых кампаний, включая истёкшие/остановленные. Ручной ввод либо генерация пяти букв/цифр D-319. Алфавит, регистр и допустимая длина ручного кода ещё определяются по D-412; пять символов — только генерация.

## Платежи, расходы и полномочия

Платёж хранит клиента, сумму, дату/время, комментарий; по умолчанию текущий момент. Способ оплаты и мультивалютность не нужны. Поступления сохраняются отдельно от результатов занятий и реальных возвратов. Баланс вычисляется по действующим исходным фактам D-190, не хранится как независимо изменяемый остаток.

Администратор читает баланс/долг и статистику, вносит/исправляет платежи с комментарием сегодняшней датой D-424. Расходы записывает сегодняшней датой; прежние расходы и экспорт — только супер D-425. Подмена даты старой операции на сегодняшнюю как обход не согласована. Полномочия удаления и форма отдельных исправлений применяются только в явно выбранных границах; неизвестные действия не разрешаются автоматически.

Расход содержит описание, сумму, дату и необязательную категорию D-196. Отдельного комментария в исходной форме нет. Список с поиском и периодом (по умолчанию текущий месяц), общими суммой/количеством и сортировкой новых первыми; XLSX использует тот же отбор и поля дата/описание/категория/сумма. Прежние права старого приложения не переносятся автоматически.

Результаты занятий имеют отдельную границу D-302/D-303: администратор исправляет в календарном месяце даты занятия по Москве; первую отметку прошлого месяца делает супер. Супер исправляет без ограничения давности. Планирование/перенос будущих занятий любых месяцев не ограничены D-304. Изменение состояния прошлого занятия требует комментария D-434. Правило дневной даты платежей/расходов не ограничивает будущий календарь.

## Возврат денег и прекращение обучения — D-454

Два режима: возврат остатка и возврат полной суммы когда-либо внесённых денег. Остаток могут вернуть сотрудники, полную сумму — супер. Полный возврат не считается суммой остатка плюс тех же поступлений: это выбранный режим возврата всех внесённых денег. Он может затронуть средства, уже потраченные на занятия, и уменьшает баланс по D-426. Результаты прошедших занятий и платежи не удаляются и не превращаются в отменённые ради обнуления баланса.

Для прекращения обучения сохраняются одноразовость операции, архивирование клиента и возможность откатить ошибку без потери истории D-426. Перед завершением операции с архивом показываются будущие занятия/действующие серии; сотрудник явно отменяет/переносит участие и завершает соответствующие серии по D-103. Пока препятствия есть, архив не выполняется. Возврат сам не отменяет будущее расписание и не обходит ограничения архива.

Откат восстанавливает финансовый эффект ошибочного возврата с сохранением его истории. Общий аудит не становится источником расчёта баланса; точная форма исправления и повторного обращения после отката ещё проектируется.

## Отчётность и прогноз

Месяц занятия — по дате начала в Москве, платежей/расходов — по дате внесения D-430. Цена занятия по-прежнему по окончанию. Встреча через полночь относится к месяцу начала независимо от момента отметки.

Месячный прогноз включает стоимость проведённых, сгоревших и запланированных участий независимо от оплаты, включая платные консультации D-184/D-186. Для пары суммируются стоимости клиентов, а занятость преподавателя не удваивается. Поступления не прибавляются к стоимости тех же занятий повторно. Прошедшие встречи без результата остаются BIZ-13; прогноз сам не подтверждает проведение и списание.

Финансовые сведения и статистика доступны администратору и суперу D-424; преподавателю закрыты, клиент видит своё. Состав стартовых экранов не меняется автоматически вместе с правом чтения отчётов. Формулы дохода, поступлений и итога должны различать движение денег и стоимость занятий; старые названия экранов не выбирают их автоматически.

## Аудит и транзакции

Аудит сохраняет автора, время, разрешённые изменения, связи и финансовые последствия D-299/D-407. Комментарий обязателен в выбранных D-424/D-434 случаях. Полные снимки объектов, персональные данные и тексты заметок в общий аудит/диагностику не попадают; история текста заметок хранится отдельно. Общий журнал доступен суперу, баланс из него не вычисляется.

Финансовые изменения, аудит и последующая работа фиксируются атомарно с постоянными ключами повторов D-400/D-401. Конкурентный расход защищён ограничениями БД и адресными блокировками. Офлайн-команды синхронизируются с актуальной проверкой прав и правил; конфликт не обходит финансовые ограничения D-449.

| FC-004 | Понедельничный результат с денежной оплатой отметили в среду | По D-049 — баланс уменьшается при отметке в среду, начисление по дате понедельника; цена по окончанию занятия |

| FC-012 | Клиент оплачивает разные услуги | Единый денежный баланс, новые абонементы исключены D-450 |
| FC-014 | Администратор исправляет занятие 14 марта | В марте разрешено в пределах прав, с 1 апреля — только супер D-302 |

| FC-018 | Два клиента, один проведён, другой отменён | Обычная стоимость и списание только первому; занятость общей встречи сохраняется |
| FC-019 | Скидочная сумма 1872.5 | 1870; конечная граница индивидуального срока исключена D-443 |
| FC-020 | Снят результат со скидкой на N занятий | Льготное использование возвращается без новой активации D-451 |
| FC-021 | Администратор открывает отчёт | Разрешено; прежние расходы и экспорт отдельно закрыты D-424/D-425 |


- У каждого участника пары обычная цена; проведение одного и отмена другого дают списание только первому.
- Цена 1200 с 14:00 применяется к окончанию в 14:00; поздняя отметка не выбирает цену момента отметки.
- Прежняя серия сохраняет длительность, будущая цена применяется по окончанию.
- До ручного результата списания нет; снятие убирает его и возвращает льготное использование без новой активации.
- 1872.5 после скидки превращается в 1870; конец встречи на конечной границе индивидуального срока скидки не подходит.
- Администратор читает статистику; прежние расходы и экспорт ему недоступны.
- Перенос будущей встречи в другом месяце разрешён при доступности; исторический результат и платежи проверяются по разным правилам давности.
- Возврат остатка и полный возврат поступлений различимы, исходные факты сохраняются; будущие записи блокируют архив до явного разрешения.
- Занятие относится к месяцу московского начала, платежи/расходы — внесения; прогноз и поступления не удваивают одни деньги.

Исторические FC-011/FC-013/FC-017 о покрытии абонементом сняты D-428. Это будущие критерии, не выполненные проверки. Вознаграждения преподавателей по D-193 остаются отложены.
