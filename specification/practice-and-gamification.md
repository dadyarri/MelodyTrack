## Два режима

В учебном режиме клиент использует конфигурацию, выбранную автором; запуск/остановка не означает право редактировать параметры. Это относится к общему и персональному ДЗ D-178, а по D-377 также к тренажёру в учебном материале. Попытки в материале имеют учебную историю аналогично ДЗ, с доступом в пределах курса/материала; это не личная история свободного режима.

Свободная практика без привязки к заданию доступна всем ролям D-245, включая клиентский портал D-179. Доступны все настройки тренажёра; они не перезаписывают конфигурацию упражнения в ДЗ. По D-338 настройки запоминаются локально отдельно для аккаунта и тренажёра, без синхронизации между устройствами. Это не делает локальной историю попыток. По D-364 собственные свободные попытки фиксируются и у клиентов, и у сотрудников; прежний запрет истории сотрудников D-334 отменён. Историю свободного режима читает только сам пользователь. Способ общего использования runtime и хранения ещё проектируется.

Преподавателю пока нужны базовые сведения D-180. Автоматическую оценку точности исполнения и её отображение не включаем в текущие правила базового учёта D-181; это не автоматическое подтверждение освоения темы или выполнения персонального ДЗ.

## Попытки, цель и видимость — D-333–D-338, D-360–D-367

После завершения тренировки автоматически сохраняются длительность без пауз, BPM, число повторов и контекст упражнения/ДЗ; для свободного режима история есть у пользователя любой роли D-364. Ручного ввода результата нет. В упражнении ДЗ преподаватель может опционально задать целевую длительность или количество повторов. Достижение цели само по себе не подтверждает освоение темы и не ставит отметку выполнения персонального ДЗ; существующие учебные права сохраняются.

Все попытки сохраняются D-337/D-364, удаление и ручная правка измерений не предусмотрены. Запуск тренажёра начинает попытку; пауза не завершает её. «Стоп» завершает с сохранением фактического результата, даже если цель не достигнута D-360. Закрытие или перезагрузка страницы сохраняет прерванную попытку; после возвращения она не продолжается автоматически D-361. Открытие страницы без запуска не начинает попытку. Технический механизм сохранения при закрытии/потере связи ещё проектируется; ответ не выбирает офлайн-режим и не означает, что доставка уже обеспечена.

История показывается в сворачиваемом блоке с пагинацией: сворачивание меняет представление, не данные. Изменение упражнения не меняет параметры, сохранённые для старых попыток; новые используют обновлённую конфигурацию D-363. Это исторические сведения о выполнении, а не независимо редактируемая копия текущего задания. Конкретная схема версий/хранения ещё не выбрана.

Пользователь любой роли читает свою свободную историю D-364. Чужие свободные попытки не видят ни преподаватель, ни администратор, ни суперпользователь. Это изменяет прежнюю часть D-335; общий доступ супера к учебной практике не отменяет данного исключения. История сотрудников теперь сохраняется, прежний запрет D-334 отменён.

В учебном режиме клиент читает свои попытки, преподаватель — назначенные ему курсы, а не другие курсы клиента; супер имеет общий учебный доступ. Попытки персонального ДЗ видят клиент, преподаватель связанного занятия и супер D-365, включая задание без курса. Администратору эти права не добавляются.

Персональное ДЗ к занятию без курса относится к учебному режиму с заданными преподавателем параметрами, а не к свободной практике. Q-347 закрыт D-365. Сохранение всех попыток не расширяет чтение закрытого содержимого чужого курса.

Локально запоминаются только настройки свободного тренажёра по аккаунту и виду тренажёра; клиент не получает этим возможность менять параметры выданного ДЗ. Сохранённые попытки — отдельные учебные факты, доступные по разрешённой области чтения. Непрерывная точная телеметрия, серверная загрузка аудио и анализ исполнения этим не утверждаются. Запрет удаления попыток не является автоматически запретом удаления локальных аудиофайлов из будущего сценария записи.

## Применение конфигурации и видео — D-366–D-371

В строке свободной попытки есть действие применения её сохранённой конфигурации к свободному тренажёру одной кнопкой, с перезаписью текущих настроек. Историческая попытка, измерения и конфигурация выданного ДЗ не изменяются. Поскольку свободная история личная, действие доступно только для собственных свободных попыток. По D-371 во время работы тренажёра копирование запрещено: действие недоступно, текущая попытка не завершается автоматически, настройки не меняются. После остановки конфигурацию можно применить. Само копирование не является запуском новой попытки.

Сотрудники могут из доступной им попытки выгрузить видео с работой тренажёра. Возможность экспорта не открывает чужую свободную историю и не расширяет область чтения курсов/ДЗ. Клиенту экспорт видео этим требованием не предоставлен. По D-375 достаточно обеспечить экспорт на компьютере; поддержка телефона не обязательна. По D-368 видео заново воспроизводит работу тренажёра по сохранённой конфигурации. Записи исполнения пользователя или микрофона в нём нет.

Метроном — отдельная отключаемая настройка тренажёра, не специальная настройка экспорта. Если при воспроизведении он включён, его звук включается в видео D-369. Экспорт сам по себе не переключает метроном.

Для зацикленной попытки базовая длительность — один цикл упражнения, с возможностью задать другое количество секунд. Для незацикленной используется сохранённая продолжительность попытки D-370. Текущие настройки тренажёра не заменяют историческую конфигурацию выбранной попытки. Для этого в конфигурации нужны признак зацикливания и состояние метронома; длительность попытки уже сохраняется.

Исходный контракт roadmap описывает браузерный экспорт представления тренажёра без серверного рендера/хранения. При проектировании v2 это исходная модель, не выбранные кодек, разрешение или инфраструктура. Расхождение roadmap между требованием silent в Staff video-recording contract и звуком метронома в Shared Metronome and Exercise Timing разрешено D-369: для v2 включённый метроном звучит в видео, безусловно беззвучный экспорт не требуется. Точный повтор случайной последовательности из исторической попытки самим сохранением настроек не обещан.

## Опыт курса и игровые баллы

Текущий XP курса уже определён D-153–D-154: это вычисление по освоенным темам. В roadmap игровые баллы для рейтингов выделены отдельно от педагогического подтверждения прогресса; тренировка не должна автоматически подтверждать освоение темы.

По D-182 практика пока не даёт рейтинговых баллов ни в режиме ДЗ, ни в свободном режиме. Факт выполнения, длительность, BPM и повторы сохраняются как базовая учебная информация, а не как основания текущего начисления. Вклад практики в рейтинг отложен до появления анализа точности. Формулы будущих наград обсуждаются вместе с ним.

Правила источников баллов, повторного получения награды, ограничений накрутки и периодов рейтинга ещё нужно описать. Упоминание истории начислений не утверждает event sourcing, шину сообщений или отдельный сервис. Исходные факты и вычисляемые итоги должны различаться по общему принципу D-154.

## Фиксация и экспорт 31.10.2026 — D-404–D-406
