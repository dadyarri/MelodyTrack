# Методика статистики

Этот документ объясняет показатели так, как их видит пользователь. Все карточки,
графики и таблицы API используют эти определения.

## Общие правила периода и области

- Период включает обе выбранные местные даты: от начала `start` до начала дня
  после `end` в выбранном часовом поясе. Правая граница не входит в расчёт.
- Запись относится к периоду и группе по местному времени её начала. Платёж и
  расход относятся к периоду и группе по местному времени своей даты.
- День, неделя и месяц — календарные группы выбранного часового пояса. Неделя
  начинается в понедельник. Первая и последняя группы обрезаются границами
  отчёта, поэтому в них нет данных соседних дат.
- Перевод местных границ в UTC учитывает сезонное изменение времени. Рабочая
  ёмкость считается по фактически прошедшему времени: смена 01:00–05:00 в день
  осеннего перевода часов может быть длиннее четырёх часов.
- Удалённые записи не учитываются. При ручном переносе серии удалённый исходник
  не считается, а новая отдельная запись считается на новой дате и с текущим
  статусом.
- Перед отчётом бэкенд материализует повторяющиеся записи до правой границы.
  Повтор на дату отпуска клиента не создаётся. Уже существующая ручная запись
  во время отпуска остаётся фактом и учитывается по своему статусу.
- Отчёт организации включает всех сотрудников, в том числе сотрудников без
  записей. Фильтр преподавателя оставляет только выбранного сотрудника.
  Запись без преподавателя входит в общие количества, услуги и выручку, но не
  создаёт рабочую ёмкость.
- Один запрос ограничен двумя годами. Клиентская таблица и список должников
  возвращают первые 100 строк после бизнес-сортировки; карточки всегда считаются
  по полному набору, а не по этим 100 строкам.

## Работа

### Карточки и статусы

- **Всего записей** — все неудалённые записи, начавшиеся в периоде, независимо
  от статуса.
- **Проведено**, **сгорело**, **отменено** и **запланировано** — количество
  записей в соответствующем текущем статусе. Сумма статусов равна общему числу.
- **Доля статуса** — количество записей статуса / все записи × 100. При пустом
  периоде доля отсутствует.
- **Доля отмен** — отменённые записи / все записи × 100. При пустом периоде
  значение отсутствует.

### Рабочее время

- **Рабочая ёмкость** — сумма рабочих интервалов сотрудников за выбранные даты
  за вычетом полных дней их отпусков. Используется текущее индивидуальное
  расписание; если оно ни разу не настроено, применяется штатное расписание:
  понедельник–пятница, 10:00–20:00. Изменение расписания пересчитывает прошлые
  отчёты; отдельная история версий расписания сейчас не хранится.
- **Занято в рабочее время** — объединение интервалов запланированных,
  проведённых и сгоревших записей внутри рабочих интервалов соответствующего
  преподавателя. Пересекающееся время считается один раз. Части записей до
  начала работы, после её окончания и во время отпуска преподавателя не входят
  в занятое рабочее время. Отменённые записи время не занимают.
- **Свободно в рабочее время** — рабочая ёмкость минус занятое в рабочее время.
  Это действительно незанятое время в расписании, поэтому значение не бывает
  отрицательным.
- **Использование ёмкости** — занято в рабочее время / рабочая ёмкость × 100.
  При нулевой ёмкости значение отсутствует; при любой комбинации пересечений и
  записей вне расписания оно не превышает 100%.

График времени разбивает те же рабочие интервалы по календарным группам.
Суммы рабочей ёмкости, занятого и свободного времени на графике равны карточкам.
Строки преподавателей включают сотрудников без записей и в сумме равны итогам
организации. Таблица часов группирует записи по местному часу начала.

### Услуги

- **Записей услуги**, **проведено** и **сгорело** — те же записи и статусы,
  сгруппированные по услуге.
- **Выручка услуги** — историческая цена проведённых и сгоревших записей услуги.
  Пробная услуга (`IsConsultation`) всегда даёт нулевую выручку, даже если в её
  истории цен по ошибке сохранена ненулевая сумма.
  Для занятия берётся последняя цена с датой действия не позже начала занятия.
  Если занятие старше первой сохранённой цены, используется самая ранняя
  известная цена. Изменение текущей цены не переписывает прошлую выручку.

## Финансы

- **Выручка по занятиям** — сумма исторических цен проведённых и сгоревших
  непробных записей, начавшихся в периоде. Пробные, запланированные, отменённые
  и удалённые записи выручку не создают.
- **Фактические платежи** — сумма платёжных операций с датой в периоде. Платёж
  может погашать прошлый долг или создавать аванс, поэтому не заменяет выручку.
- **Расходы** — сумма расходных операций с датой в периоде. Таблица и диаграмма
  статей группируют ровно эту сумму; отсутствие статьи называется «Без статьи».
- **Чистая прибыль** — выручка по занятиям минус расходы периода. Платежи в эту
  формулу не входят, потому что показывают движение денег, а не начисление.
- **Долг клиентов на конец периода** — для каждого клиента `max(0, вся выручка
  по состоявшимся занятиям до правой границы − все платежи до правой границы)`;
  карточка суммирует долг всех клиентов. Переплата одного клиента не уменьшает
  долг другого. Таблица показывает только 100 крупнейших долгов и поэтому при
  большом числе должников может быть меньше карточки.
- **Средняя выручка за занятие** — выручка периода / число проведённых и
  сгоревших непробных записей периода. При отсутствии таких записей значение
  отсутствует.

Строки услуг и график выручки в сумме равны карточке выручки. Графики платежей,
расходов и прибыли в сумме равны своим карточкам. Платежи, расходы, прибыль,
долг и статьи расходов показываются только для организации: текущая модель не
связывает их с преподавателем достаточно надёжно. При фильтре преподавателя API
возвращает `null`, а не приблизительное распределение. Выручка и средняя
выручка за занятие при таком фильтре остаются доступными, потому что запись
содержит преподавателя.

## Клиенты

Клиентские показатели используют только проведённые и сгоревшие непробные
занятия в выбранной области преподавателя. Пробная услуга остаётся фактом
работы в рабочем отчёте, но не превращает лида в ценного или активного клиента.
Отмена, удаление или ещё не проведённая запись не являются посещением.

- **Новый клиент** — клиент, чьё первое состоявшееся занятие во всей доступной
  истории попало в период. Источник берётся из текущей карточки клиента.
- **Активный клиент** — уникальный клиент хотя бы с одним состоявшимся занятием
  в периоде.
- **Вернулся из прошлого периода** — клиент, активный и в выбранном периоде, и
  в непосредственно предыдущем периоде той же длины.
- **Удержание** — вернувшиеся клиенты / активные клиенты прошлого периода × 100.
  При отсутствии активных клиентов в прошлом периоде значение отсутствует.
- **Средняя частота посещений** — состоявшиеся занятия периода / активные
  клиенты периода. При отсутствии активных клиентов значение отсутствует.
- **Выручка клиента за всё время** — историческая выручка всех его состоявшихся
  занятий до конца периода в выбранной области. **Средняя выручка клиента** —
  среднее этой величины по клиентам с положительной выручкой.
- **Средний календарный интервал** — среднее число календарных дней между
  последовательными состоявшимися занятиями клиента. Для одного занятия
  значение отсутствует.
- **В отпуске** — неактивный в периоде клиент, чей отпуск включает последний
  день отчёта. Такой клиент не помечается как находящийся под риском или
  потерянный.
- **Под риском** — неактивный клиент, для которого после последнего
  состоявшегося занятия прошло от 31 до 60 дней включительно, не считая дней
  его отпусков.
- **Потерян** — неактивный клиент, для которого после последнего состоявшегося
  занятия прошло больше 60 дней, не считая дней его отпусков.
- **Неактивен** — клиент без посещения в периоде, который не попал в три
  предыдущие категории.

Сумма посещений на графике равна числу состоявшихся занятий периода. Суммы
новых и активных клиентов по источникам равны карточкам. Значения за всё время
не обязаны складываться в выручку выбранного периода: это разные горизонты.

## Проверочная матрица формул

| Сценарий | Ожидаемое правило |
| --- | --- |
| Пустой или частичный период | Нулевые суммы; проценты без знаменателя отсутствуют; группы обрезаны периодом |
| День, неделя, месяц | Каждая операция и запись попадает ровно в одну местную группу |
| Перевод часов | UTC-границы и фактическая длительность рабочей смены учитывают переход |
| Сотрудник без записей | Есть строка и рабочая ёмкость; занятое время равно нулю |
| Индивидуальное расписание отсутствует | Используется штатное расписание понедельник–пятница 10:00–20:00 |
| Рабочее расписание изменено | Весь выбранный период пересчитывается по текущему расписанию; отдельной истории версий нет |
| Отпуск преподавателя | Ёмкость дня равна нулю; существующая запись сохраняет статус и финансовый смысл |
| Отпуск клиента | Повтор не создаётся; часы отпуска останавливают счётчик риска и потери |
| Пересекающиеся записи | Общие количества сохраняются; занятое пересечение считается один раз |
| Запись вне рабочих часов | Считается в статусах и, если состоялась, в выручке; не уменьшает свободное рабочее время |
| Отмена, удаление, перенос | Отмена не занимает время и не даёт выручку; удалённый исходник не считается; перенос считается на новой дате |
| Изменение цены | Каждое состоявшееся занятие использует цену на момент начала; раннее — первую известную |
| Пробная услуга с любой ценой | Считается записью и занимает время, но не даёт выручку, долг или клиентскую ценность |
| Платёж, аванс и частичная оплата | Платёж попадает в движение денег по своей дате; долг считается накопительно на конец периода |
| Более 100 должников | Карточка содержит полный долг, таблица — только 100 крупнейших строк |
| Несколько преподавателей | Итоги организации равны сумме строк преподавателей; запись без преподавателя не создаёт ёмкость |
| Предыдущий период | Удержание использует соседний период той же длины без пересечения |

Статистика доступна администраторам и суперпользователям. Отчёт не делает
выводов о причинах оттока и не распределяет общие расходы между преподавателями.
