# Методика статистики

Все три отчёта используют один закрытый период местных дат: от начала `start`
в выбранном часовом поясе до начала дня после `end`. Записи на правой границе не
входят в отчёт. Удалённые записи не учитываются. Повторяющиеся записи перед
расчётом создаются бэкендом на весь требуемый период.

Статистика доступна только администраторам и суперпользователям. По умолчанию
отчёт охватывает всю организацию; при необходимости можно выбрать одного
преподавателя. Один запрос ограничен двумя годами, а подробные списки клиентов и
должников — первыми 100 строками после бизнес-сортировки.

## Работа

- **Записей** — все неудалённые записи, начало которых попало в период.
- **Проведено**, **отменено** и **сгорело** — записи с соответствующим текущим
  статусом. Изменённый статус учитывается только в своём текущем состоянии.
- **Занято часов** — длительность запланированных, проведённых и сгоревших
  записей. Отменённые записи время не занимают.
- **Доступно часов** — рабочие интервалы выбранных преподавателей за период без
  дней отпуска. Если индивидуальное расписание не задано, используется штатное
  расписание по умолчанию.
- **Загрузка** — занятые часы / доступные часы × 100. При нулевом доступном
  времени значение отсутствует.
- **Доля отмен** — отменённые записи / все записи × 100. При отсутствии записей
  значение отсутствует.
- **Выручка услуги** в подробной таблице — цена проведённых и сгоревших записей
  на дату занятия. Берётся последняя цена, начавшая действовать не позднее
  занятия; для более ранней записи используется самая ранняя известная цена.

Итоги, временной график и таблицы строятся из одного набора записей. Часы начала
на графике занятости определяются в выбранном часовом поясе.

## Финансы

- **Выручка по занятиям** — историческая цена проведённых и сгоревших записей,
  начало которых попало в период.
- **Фактические платежи** — сумма записей платежей, дата которых попала в период.
  Это отдельная величина: платёж не заменяет выручку и может относиться к долгу
  или авансу другого периода.
- **Расходы** — сумма записей расходов, дата которых попала в период.
- **Чистая прибыль** — выручка по занятиям минус расходы периода.
- **Долг** на конец периода — положительная разница между всей выручкой клиента
  по состоявшимся занятиям до правой границы и всеми его платежами до той же
  границы. Переплата не превращается в отрицательный долг.
- **Средний чек** — выручка / количество проведённых и сгоревших записей периода.

Платежи, расходы, чистая прибыль и долг доступны только без фильтра
преподавателя: в текущей модели платежи и расходы нельзя достоверно приписать
отдельному преподавателю. При выбранном преподавателе API возвращает для этих
показателей `null`, а не приблизительное значение.

## Клиенты

Клиентская статистика использует только проведённые и сгоревшие занятия в
выбранной области преподавателя.

- **Новый клиент** — клиент, чьё первое состоявшееся занятие попало в период.
  Источник берётся из карточки клиента.
- **Активный клиент** — клиент хотя бы с одним состоявшимся занятием в периоде.
- **Вернулся из прошлого периода** — клиент, активный и в выбранном, и в
  непосредственно предыдущем периоде той же длины.
- **Удержание** — вернувшиеся клиенты / активные клиенты прошлого периода × 100.
- **Частота посещений** — состоявшиеся занятия периода / активные клиенты.
- **Ценность клиента** — историческая выручка по всем его состоявшимся занятиям
  до конца периода в выбранной области. Средняя ценность считается по клиентам
  с ненулевой ценностью.
- **Под риском** — в периоде занятий не было, а с последнего состоявшегося
  занятия прошло от 31 до 60 дней включительно.
- **Потерян** — в периоде занятий не было и с последнего состоявшегося занятия
  прошло больше 60 дней.

Отчёт не делает выводов о причинах оттока или влиянии цены. Анализ изменений
цен удалён, пока для него не появятся проверенная методика, достаточные выборки
и корректное распределение расходов.
